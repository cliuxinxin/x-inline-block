# X 一键拉黑

一个无需账号授权的 Chrome 扩展。在 X/Twitter 的帖子作者名后显示红色“拉黑”，单击后自动完成 X 原生的“更多 → 拉黑 → 确认”流程。

## 下载

打开本项目的 GitHub Releases 页面，在最新版本的 **Assets** 区域下载：

`x-inline-block-v1.0.0.zip`

请不要下载 GitHub 自动生成的 `Source code (zip)`，它包含开发文件，不是为直接安装准备的发布包。

## 手动安装

1. 下载 `x-inline-block-v1.0.0.zip`。
2. 将 ZIP 完整解压到一个固定目录；安装后不要删除这个目录。
3. 打开 Chrome，在地址栏输入 `chrome://extensions/` 并回车。
4. 打开页面右上角的“开发者模式”。
5. 点击左上角“加载已解压的扩展程序”。
6. 选择刚才解压后的文件夹。正确的文件夹打开后应能直接看到 `manifest.json`，不要选择它的上级目录。
7. 扩展列表中出现“X 一键拉黑”后，打开或刷新 `https://x.com/`。

Chrome 不允许直接安装普通网站下载的 ZIP，因此必须先解压，再使用“加载已解压的扩展程序”。

## 使用

在首页、搜索结果、评论区或用户主页的帖子中，单击作者名后的红色“拉黑”。扩展不会再显示自己的确认框，而会立即操作 X 的原生菜单并确认。操作期间按钮显示“处理中…”，成功后显示“已拉黑”。

## 隐私

- 不调用 X 的私有接口。
- 不读取、保存或上传 Cookie、密码和登录凭据。
- 不包含后台服务、统计或网络请求。
- 仅在 `x.com` 和 `twitter.com` 页面中运行。

## 限制

X 的页面结构可能随时调整；若其测试标识或菜单文案改变，自动操作会安全停止并恢复按钮，不会猜测点击其他菜单项。真实账号的最终拉黑操作必须在已登录 X 的 Chrome 页面中手动验收。

扩展不处理广告、当前账号自己的帖子以及右侧关注推荐列表。

## 故障排查

- 没看到“拉黑”：刷新 X 页面，并确认扩展已启用且网站访问权限允许 `x.com`。
- 按钮恢复并显示失败提示：X 的菜单可能尚未加载或页面结构已更新，可重试一次。
- 更新源码后：在 `chrome://extensions/` 中点击本扩展的刷新图标，再刷新 X 页面。
- Chrome 重启后扩展消失：确认解压目录仍然存在，并重新执行“加载已解压的扩展程序”。

## 开发验证

